## 🪝 How To Use This File

Print it, or keep it open in an editor and tick the boxes as you go. Ticking a box in markdown is changing `[ ]` to `[x]`.

**Fill in a row when the deliverable exists — not when you finished reading.**

| Column | What goes in it |
|---|---|
| **✓** | `[x]` when the mini-project is built and it works |
| **Module** | Link to the module file |
| **Mini-project** | The thing that has to exist |
| **Started** | Date you opened the module |
| **Done** | Date the deliverable existed |
| **Score** | Column count from the [project rubric](rubrics.md#-rubric-1--the-project-rubric), e.g. `6P/2D` = 6 Proficient, 2 Developing |
| **🏅** | Tick when the badge is earned. Say the badge name out loud. Yes, really. |

> 🔑 **The scoring shorthand.** `B` = Beginning · `D` = Developing · `P` = Proficient · `E` = Exceptional. `5P/2D/1E` means five Proficient, two Developing, one Exceptional. **All-P is an excellent project** — see the [percentage trap](rubrics.md#-turning-rubrics-into-a-number-if-you-have-to).

### The one rule for badges

**A badge is not awarded for finishing. It is awarded for the deliverable existing and working.** The difference matters — a learner who gets the badge for showing up learns that badges are noise. A learner who has to make something work first learns that they are the kind of person who makes things work.

Say the name out loud when you award it. It's silly. It works.

## ✅ Tracker Self-Check

<details>
<summary><strong>Click to reveal the six questions</strong></summary>

1. **Is the last tick within the last two weeks?** If not, the rhythm has slipped. That's fine — restart with a retrieval session, not with new material.
2. **Are there `[x]` boxes with no date?** Ticking without dating means the tracker has become decorative. Dates are what make the growth snapshot possible.
3. **Are there modules with a done date but no rubric score?** Score them, even retroactively and roughly. Row 3 (method correctness) and Row 5 (failure analysis) are the two that matter.
4. **Has any badge been awarded for showing up rather than for a working deliverable?** If so, quietly raise the bar. Badges only work if they mean something.
5. **Is the secret-badge list empty?** Then nobody is watching for the moments that actually matter. Reread it and award one this week.
6. **When was the last exit check run?** Not the assessment — the no-notes conversation. If it's been more than a level, run one now, unannounced, over food.
