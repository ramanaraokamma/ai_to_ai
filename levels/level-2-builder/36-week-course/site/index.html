Level 2 · Builder · The 36-Week Course

One school year from a blank file to three trained models on an honest split.

Thirty-six classes of 60–75 minutes for one 7th grader who has never written a line of code, taught by an adult who knows neither Python nor AI. Code every single week. Maximum four new pieces of syntax and five new words per week, all year.

“The teacher opens the week’s file 20 minutes before class, and that is all the preparation they get. They must be able to teach a confident, correct 70-minute lesson from that one file — including reading, explaining and debugging code they have never seen.”— the single design constraint that shaped every page

🧲 The syntax ladder

Every one of the 132 Python constructs in Level 2, in the week it first appears. Nothing is ever used before the week it appears here — so you can always answer “have we met this yet?” in five seconds. If a student uses something whose week is still ahead of you, they found it on the internet, and the honest reply is “nice — we meet it properly in week N, can you explain it to me?”

Every Python construct in Level 2 and the week it is first taught
WeekNew constructWhat it does, in one line
w01 print("text") Puts text on the screen
w01 # a comment A note for humans; Python ignores it
w01 + - * / Add, subtract, multiply, divide. / always gives a decimal
w01 print(a, b, c) Prints several things on one line, separated by spaces
w02 name = value Puts a value in a named box. The name goes on the left, always
w02 type(x) Tells you what kind of value x is
w02 int("12") Turns text that looks like a whole number into a whole number
w02 float("3.5") Turns text that looks like a decimal into a decimal
w03 f"Hi {name}" A string with values dropped into it
w03 f"{x:.2f}" The same, rounded to 2 decimal places for display
w03 // and % Whole-number divide, and the remainder left over
w03 ** Raise to a power. 2 ** 3 is 8
w04 input("prompt") Asks the human a question. Always hands back text
w04 int(input("Age? ")) Ask, then convert straight away — the safe habit
w04 str(x) Turns a number into text so you can glue it onto a string
w04 round(x, 2) Rounds a number to 2 decimal places (a real number, not just display)
w05 == and != Is it equal? Is it not equal? Two equals signs, not one
w05 < > <= >= Less than, greater than, and the "or equal to" versions
w05 if condition: Run the indented block only if the condition is True
w05 else: Run this block instead, when the if was False
w06 elif condition: Another question, asked only if all the ones above were False
w06 and True only when both sides are True
w06 or True when either side is True
w06 not Flips True to False and back
w07 for i in range(n): Repeat the block n times, with i counting 0, 1, 2 …
w07 range(start, stop, step) The same counting, but you choose where it starts, stops and how it steps
w07 total += x Short for total = total + x. The accumulator move
w07 "=" * 20 Twenty equals signs. Multiplying a string repeats it
w08 while condition: Keep repeating for as long as the condition stays True
w08 break Leave the loop right now
w08 continue Skip the rest of this trip round the loop and start the next one
w08 random.randint(a, b) A random whole number from a to b, both included
w09 def name(): Give a block of code a name
w09 name() Run the block that has that name
w09 return value Hand a value back out of the function to whoever called it
w10 def f(a, b): Parameters — boxes the caller fills in
w10 def f(a, b=0): A default value, used when the caller doesn't supply one
w10 f(b=3) A keyword argument — name the parameter you're filling
w10 None Python's word for "no value". What a function with no return gives back
w11 [1, 2, 3] A list — many values under one name

⚠ Watch out: do not teach Week 29 and Week 33 in the same fortnight if you can help it.
