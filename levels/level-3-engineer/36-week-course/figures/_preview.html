Composition patterns (7)

pattern-pipeline 0 0 800 400

Four equal boxes, arrows in the gaps, a NUMBER on every stage so the order survives greyscale. Stage colours run data → accent → model → correct: the data, the danger, the learned thing, the verdict. The stage glyphs carry NO text, because a motif's own 12px labels would fall under the floor at this size — the words live in the 18px stage label.

pattern-before-after 0 0 800 400

Mirror the geometry EXACTLY so the eye only has to find the one difference. The tick and cross badges, not the panel colour, say which side is which. One change per figure — if you changed two things, draw two figures.

pattern-progression 0 0 800 400

Three equal panels, numbered, with IDENTICAL data in each. The numbers carry the progression; the panel colour only says good or bad. Too-small and diverging are both wrong-red, told apart by the SHAPE of the walk. The embedded motifs sit at scale 1.2, never below 1.0.

pattern-annotated-chart 0 0 500 500

The chart and the tables are matched by NUMBER, not by a leader line — three leaders across a chart would cross the curve. Every mark on the curve that you name must have its numbers printed somewhere on the same page, or the reader cannot check you.

pattern-structure 0 0 800 400

One block per tensor, one shape per block, and the pairs that must agree boxed and joined. The vertical legs of the join run over a pale block fill, which is legal and reads cleanly at 2px dashed. Print the shapes in MONO so the digits line up; everything else stays sans.

pattern-matrix 0 0 800 400

Outline the ROW you used, the COLUMN you used and the CELL you got, in the same accent, and print every multiplication. A matrix figure without arithmetic in it has taught nobody anything — see §3.2.

pattern-error-fix 0 0 800 400

The failing artefact on the left, the working one on the right, an arrow between, a one-line diagnosis under each. Both panels sit at scale 1.0 — shrinking a terminal would drop its 12px mono text below the floor. The right panel must be the SAME program, so only one thing changed.
